Kwrt 定制编译

目标设备：x86_64（N4100-4L）。这里只放非敏感参数；后台密码、PPPoE 账号密码请刷机后在路由器后台设置。

基本设置

分区越大，可装的 Docker 镜像和文件越多，但刷机镜像也越大。盘是 32G mSATA，默认值沿用 Kwrt 的 1004MB。

软件包

包名都已核对存在于包源，但“存在”不等于一定能编过；编译前会再核对一次，有缺失会直接报错，不会白编几小时。

触发编译

令牌只在点击“触发编译”时发往 api.github.com，不会发到其他地方。建议使用只授权这一个仓库、仅 Actions 读写权限的 fine-grained 令牌。不想填令牌，可用“复制命令”。
